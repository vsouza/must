## B — Por perto, agora (`Descobrir.png`)
5. `Services/Nearby/NearbyService.swift` junta quatro fontes num ranking local, raio 600 m, sem rede nova além das que já existem + duas gratuitas:
   - **Board**: lugares seus abertos agora (sempre primeiro se score alto).
   - **Google Places Nearby Search (New)** com `rankPreference: POPULARITY`, `includedTypes` por filtro (restaurant/cafe/bar/museum/tourist_attraction/park), field mask `id,displayName,location,rating,userRatingCount,currentOpeningHours.openNow,primaryType` (SKU Pro; 1 chamada por abertura, cache 30 min por célula de 200 m).
   - **Wikipedia geosearch** (`pt.wikipedia.org/w/api.php?action=query&list=geosearch&gscoord=lat|lng&gsradius=600` e `ja.`/`en.` como fallback; sem chave) → pontos históricos/arquitetura com artigo; mostrar "artigo em pt".
   - **Foursquare Places** `places/search` com `sort=POPULARITY` + `open_now=true` → "em alta neste horário" quando `popularity` > 0,9.
   - **Experiências** (parte C) com horário hoje a < 1 km.
   Score = f(rating, log(contagem), distância, aberto agora, horário do dia × categoria, novidade pra você — fora do board pesa +, já feito pesa −). Dedupe por nome+distância < 60 m.

## C — Experiências e ingressos (`Experiencias.png`, `Ingresso.png`)
8. Novo tipo `ListKind.experience` ("Must do", cor `night`), com `Extra.experience: ExperienceInfo { supplier: .viator/.getYourGuide/.klook/.airbnb/.other, productCode, url, durationMinutes, priceFrom, currency, rating, reviewCount, meetingPoint: String?, meetingLat/Lng, languages, groupMax, freeCancellationHours, sessions: [Session] }` e `Ticket { confirmation, qrPayload?, pdfURL (arquivo local), paid, people, cancelUntil, walletPassURL? }` ligado a uma `Session`. Ingresso comprado = **âncora** no solver (já tratado como reserva) e aparece em Reservas.
9. **Fontes** (`Services/Experiences/`), cada uma com protocolo + fake, todas opcionais:
   - **Viator Partner API — Basic access (afiliado)**: cadastro no programa de afiliados da Viator/Tripadvisor dá uma chave *basic*; endpoints disponíveis nesse nível: `/products/search`, `/search/freetext`, `/products/{code}`, `/availability/schedules/{code}`, `/attractions/search`, `/locations/bulk`, `/destinations`, `/exchange-rates`. **Não** dá booking nem reviews — a compra é por deep link afiliado (`productUrl` do produto). Cache 24 h; busca por `destId` de Tóquio/Kyoto/BH + texto + filtro de data.
   - **GetYourGuide Partner API** (programa de parceiros; chave após aprovação; spec pública no GitHub `getyourguide/partner-api-spec`): `/tours` por `coordinates` + `radius`, `/tours/{id}/availabilities`. Compra por link com `partner_id`.
   - **Klook**: só programa de afiliados com links/widgets; a API de distribuição é fechada. Implementar **apenas colar link**.
   - **Airbnb Experiences**: API só por convite (Preferred Software Partner). Implementar **apenas colar link**.
   - **Colar link** (qualquer uma das quatro + e-plus/Peatix/Sympla): `og:title`, `og:image`, `og:description` + o extrator no aparelho (`@Generable struct ExtractedExperience { title, supplier, price, currency, durationMinutes, meetingPoint, date, time, languages }`). Guardar a URL como `url`; o botão "Ver no <fornecedor>" abre no navegador.
   - Chaves `VIATOR_KEY`, `GYG_KEY` em `Secrets`; sem chave, a fonte some e a tela vira "colar link + o que você já tem".
10. **Tela Experiências**: busca com "perto · 3 km", chips (Qualquer dia / Hoje / dia da viagem / ≤ preço / ≤ 2h / Cancela grátis), card "Achou no Airbnb, Klook ou GetYourGuide? Cola o link", resultados com foto tingida na cor da lista, badge do fornecedor, título, duração · grupo · idioma · rating · contagem, preço mono, chip de disponibilidade ("sáb 15 · 10:00 livre" vindo de `/availability/schedules`), "já no board", e **"conflita: Udatsu 19:00"** quando a sessão bate numa âncora. Botões Adicionar (vira `Place` tipo experience) e Ver no fornecedor. Ícone de ingresso no topo abre a lista "Meus ingressos" (os `Ticket`s).
11. **Tela Ingresso**: tags (Must do · Experiência / confirmado · âncora / fornecedor), título, meta; **o ingresso** em card preto com recorte lateral: dia, hora grande, "chegar 09:45 · saia de <casa> 09:12" (ETA do RoutesService), QR (gerado de `qrPayload` com CoreImage `CIQRCodeGenerator`; se só houver PDF, mostrar a 1ª página), confirmação mono, pago (× pessoas, "exceção aceita" quando fora do orçamento), cancelamento até, botões "Mostrar QR grande" (tela cheia, brilho máximo), "Abrir PDF", "+ Wallet" (só se o fornecedor der `.pkpass`; senão esconder). Card de ponto de encontro (nome + nameLocal, como chegar com linha/tempo/preço, link do fornecedor, "Depois: fica a 9 min de X — mas é almoço duplo" quando o solver detectar conflito com a regra de refeições). Botões "Ir ao encontro" e "Ver o dia".
12. **Adicionar ingresso a um lugar** que já existe (ex.: teamLab): em Editar lugar → Reserva ganha "Anexar ingresso" (PDF/foto/colar código) e vira `Ticket`. Compartilhar → Must (`must://add?url=`) com um PDF de ingresso cai aqui: o extrator lê confirmação, data, hora e nome do lugar e sugere o `Place` correspondente.

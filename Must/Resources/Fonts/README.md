# Fontes (OFL 1.1)

Baixadas de [google/fonts](https://github.com/google/fonts) e registradas em `UIAppFonts` (app e widgets). Licenças em `licenses/`.

| Arquivo | Família | PostScript | Uso |
|---|---|---|---|
| `Archivo.ttf` | Archivo (variável, wght 100–900, wdth 62–125) | `ArchivoRoman-Regular`, `Archivo-SemiBold`… | UI |
| `InstrumentSerif-Italic.ttf` | Instrument Serif | `InstrumentSerif-Italic` | voz do usuário, legendas |
| `InstrumentSerif-Regular.ttf` | Instrument Serif | `InstrumentSerif-Regular` | — |
| `GeistMono.ttf` | Geist Mono (variável, wght 100–900; projeto vercel/geist-font) | `GeistMono-Regular`… | horas, ¥/R$, códigos |
| `ZenKakuGothicNew-Medium.ttf` / `-Bold.ttf` | Zen Kaku Gothic New | `ZenKakuGothicNew-Medium` / `-Bold` | kanji |

Fontes variáveis: em SwiftUI usar `Font.custom("Archivo", fixedSize:).weight(_:)` — ver `DesignSystem/Fonts.swift`.
